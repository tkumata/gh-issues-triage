## Goal

取得済みの Issue を、列見出しのクリックで比較できるようにする。
一覧に Author、Assignees、作成日を表示する。
今回の実装を、バージョン `0.1.11` の対象とする。

## Scope

- GitHub 応答の追加属性と、TUI の表示データ。
- Author、作成日時、重要度、番号の並べ替え。
- 7列の幅計算、折り返し、見出しクリック領域。
- 検索、仮選択、スクロール、ブランチ作成との接続。
- 関連テストデータ、README、現在の要求・仕様・設計。
- `Cargo.toml` と `Cargo.lock` のパッケージバージョン。

## Non-goals

- `next <owner>/<repo> --format json` の動作変更。
- キーボードによる並べ替え。
- Ready、Assignees、Issues による並べ替え。
- 並べ替え条件の永続化、新しい設定、新しい依存関係。
- 取得上限、認証方式、Jev の判定、検索対象の変更。
- 見出しの固定表示、追加の API 呼び出し。
- 本計画の承認前の実装、タグ作成、リリース公開。

## Required Behavior

以下の要求と仕様は、2026-10-23 の実装承認で確定した。
本計画の要求と仕様は、必須 (MUST) とする。

- 既定の順序は、既存の重要度降順と同点の取得順を維持する。
- マウスだけで、4項目の昇順と降順を切り替えられる。
- 並べ替え後も、表示と操作対象が同じ Issue に対応する。
- `next` は、新属性の検証による新しい失敗条件を持たない。
- 仕様には、Open Questions への回答を反映した。

承認済み仕様の要点:

- 列順は、重要度、Ready、番号、Author、Assignees、日付、Issues。
- 別列の初回クリックは昇順、同じ列の再クリックは方向反転。
- 比較キーが同じ場合は取得順、Author の欠損は常に末尾。
- Author は、大小文字を区別した `login` 順。
- Assignees は表示専用とし、全員を `login` 昇順にして表示する。
- 日付表示は JST の `YYYY-MM-DD`、比較は作成日時全体。
- ソート後に検索を実行した場合、並べ替え条件を維持する。
- 並べ替え後は、仮選択を解除してスクロール位置を維持する。

2026-10-23 の回答による決定事項:

- 列順、方向記号、スクロールする見出しは、提示案を採用する。
- 別列は昇順から開始し、同値は取得順とする。
- Assignees による並べ替えは、対象外とする。
- 日付表示は、UTC から JST へ変更する。
- ソート後の検索は、並べ替え条件を維持する。
- 並べ替え後は仮選択を解除し、一覧の先頭へ移動しない。

  - Jev の入力と既存ランキングを維持する。
  - `next` の出力、選定、失敗条件を維持する。
