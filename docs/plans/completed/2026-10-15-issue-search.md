## Goal

ユーザーが、一覧から確認したい Issue を検索で絞り込めるようにする。

## Scope

- タイトルと本文への、英字の大小を区別しない部分一致。
- 空白（全角空白を含む）で区切った各語の AND 検索。
- 端末幅に合わせた1行の検索入力欄。
- Enter とクリック可能な検索ボタンによる検索実行。
- 日本語入力、フォーカス、表示対象とブランチ作成対象の対応。
- 既存文書の追加節と `README.md` の操作説明。

## Non-goals

- 起動時の取得上限10件の変更。
- GitHub 上の全 Issue の検索。
- GitHub と Jev への検索時の追加リクエスト。
- `next <owner>/<repo> --format json` の変更。
- 正規表現、OR 検索、フレーズ検索、Unicode 正規化。
- 新しい依存関係、設定、永続化、汎用 UI 層。

## Required Behavior

- 空白で区切ったすべての語がタイトルまたは本文に一致する Issue だけを表示する。
- 語順は問わず、各語がタイトルと本文に分かれていても一致する。
- 検索結果は、既存の重要度順を維持する。
- 再検索は、起動時に取得した全件を対象にする。
- IME の変換確定用 Enter は、検索を実行しない。
- 変換終了後の Enter とボタンクリックは、検索を実行する。
- 検索編集中の文字は、既存のショートカットへ渡さない。
- 空文字または空白だけの検索は、取得済み全件を表示する。
- 検索結果が0件の場合も、再検索を受け付ける。
- 数字キーとボタンは、表示中の Issue に対応する。
- 操作の詳細は、追加仕様の承認対象の提案に従う。
