## Required Behavior

### Issue 本文で指定された要求

以下の要求は必須 (MUST) とする。

- 一覧下部の常設ヘルプ文字列を削除する。
- 常設ヘルプの代わりに Help ボタンを表示する。
- Help ボタンのクリックでダイアログを表示する。
- ダイアログは、操作方法、検索方法、アイコンの意味を説明する。
- Help ボタンは、左右の余白を含めて色を反転する。
- Help ボタンは、左右の余白で横幅を広げる。
- 検索入力欄と Search ボタンを1行で表示する。
- Search ボタンは、左右の余白で横幅を広げる。
- Search ボタンは、左右の余白を含めて色を反転する。

```text
Keywords: [ Type keywords... ]    Search
```

### 変更前の状態

- 検索部分は、入力欄、ボタンと案内、空行の3行を使用する。
- Search ボタンは、` Search ` を反転表示する。
- Search ボタンの判定位置は、画面の2行目に固定されている。
- 検索部分の高さは、一覧操作の座標補正にも使用される。
- 一覧下部は、操作説明とブランチ状態の凡例を表示する。
- ブランチの確認不能理由は、凡例と同じ配列に保持される。
- 重要度の説明は、テーブル文字列の先頭に含まれる。
- 作成結果の画面には、既存のスクロールと復帰処理がある。

### 承認済み仕様

以下は、2026-10-26 にユーザーが承認した仕様である。
要求レベルは必須 (MUST) とする。

- Help ボタンは、一覧の最下部の左端に1行で表示する。
- ボタンの文字列は、`   Help   ` と `   Search   ` とする。
- ボタン内の左右の余白もクリック対象にする。
- 反転属性は、各ボタンの直後で解除する。
- 検索入力欄と Search ボタンの間に半角空白を1文字置く。
- 検索部分の高さを1行へ変更する。
- Search ボタンの幅を確保し、残りを入力欄の幅に使用する。
- 入力欄以外のクリックでは、検索入力へ切り替えない。
- 状態別の入力案内は、Help ダイアログへ移す。
- 空欄の灰色案内、入力中の枠強調、カーソル表示を維持する。
- 下部のブランチ凡例は、Help ダイアログへ移す。
- 重要度の説明は、現在の一覧上部に維持する。
- ブランチの確認不能理由は、一覧に引き続き表示する。
- 高さ計算は、確認不能理由の折り返し後の行数を含める。
- ダイアログは、一覧の上に重ねる枠付きの表示とする。
- 内容が収まらない場合、ダイアログ内をスクロールできる。
- ダイアログ内では、`j` / `k`、上下矢印で1行移動する。
- ダイアログ内では、PageUp / PageDown で画面単位に移動する。
- Esc、Enter、閉じるボタンでダイアログを閉じる。
- Ctrl+C は、既存の終了操作を維持する。
- ダイアログ中の入力を、一覧や検索の操作へ渡さない。
- 復帰時は、検索語、入力状態、並べ替え条件を維持する。
- 復帰時は、仮選択、一覧とセルのスクロール位置を維持する。
- ダイアログは、検索範囲、AND 検索、空欄での解除を説明する。
- ダイアログは、一覧操作、並べ替え、ブランチ作成を説明する。
- ダイアログは、`🌿`、空欄、`?`、`↑`、`↓` の意味を説明する。
- ダイアログは、重要度と Ready の意味を説明する。
- 日本語の表示幅、制御文字対策、端末復元を維持する。
- 表示に必要な幅や高さがない場合、理由を示して失敗終了する。
